# 受迫非线性单摆的动力学预测

## 运行

```bash
python -m pip install -r requirements.txt
python main.py --predict   # 使用附带权重，生成预测与图表
python main.py             # 从头生成数据、训练并预测
```

本次运行环境：Python 3.13.5、PyTorch 2.10.0，CPU。

## 实验设计

研究无量纲方程，保留非线性项，不采用小角度近似：

$$\ddot\theta+0.5\dot\theta+\sin\theta=A\cos(\tfrac23t+\phi_0).$$

用四阶 Runge–Kutta（RK4）生成无噪声轨迹：内部步长 0.025，采样间隔 0.05，时长 40。
初始摆角、相位分别均匀采自 $[-\pi,\pi]$，初始角速度采自 $[-2,2]$。

训练幅值为 0.5、0.9、1.2，每个幅值生成 32 条训练轨迹、8 条验证轨迹；
另对 0.5、0.9、1.05、1.2 各生成 16 条独立评估轨迹，其中 1.05 是未参与训练的幅值插值实验。
三个集合分别使用随机种子 42、43、44，按整条轨迹隔离；训练集共有 76,800 个相邻状态对。

输入为 `[sinθ, cosθ, ω, A, sinφ, cosφ]`，其中 `ω=θ̇`、`φ=(2/3)t+φ₀`。
模型是 `6 → 64 → 64 → 2` 的全连接网络，两个隐藏层均用 Tanh。
它学习相邻状态的平均变化率 `(下一状态−当前状态)/0.05`，再通过 `下一状态=当前状态+0.05×网络输出` 预测。
输入与目标的标准化参数只由训练集计算；以标准化变化率的均方误差训练。
使用 Adam、批量 1024、160 轮，学习率从 0.001 余弦下降到 0.00001，保留验证损失最低的第 158 轮权重。

单步预测每次输入真实当前状态；自由滚动预测只提供初值，此后不断喂回自己的预测，未来外力相位仍作为已知输入。
对照方法为角速度保持不变的匀速外推，不使用真实受力公式。

## 本次结果

以下汇总全部 64 条独立评估轨迹。摆角使用圆周距离 `atan2(sin(预测−真实), cos(预测−真实))` 计算 RMSE。
“前 H 时间”统计从第一个预测点到 H 的全部时间点，不是仅统计 H 时刻；时间均为无量纲。

| 预测任务 | MLP 摆角 RMSE / rad | MLP 角速度 RMSE | 匀速外推摆角 RMSE / rad |
|---|---:|---:|---:|
| 单步，间隔 0.05 | 0.000152 | 0.000238 | 0.000889 |
| 自由滚动，前 5 时间 | 0.013565 | 0.008343 | 1.500772 |
| 自由滚动，前 10 时间 | 0.024426 | 0.015867 | 1.687405 |
| 自由滚动，前 40 时间 | 0.539004 | 0.353200 | 1.767928 |

本次实验中短期预测优于匀速外推，但幅值 1.05、1.2 的长期误差明显增大。
前 40 时间的展开摆角 RMSE 为 2.450032 rad，说明圆周误差不能反映全部累计转圈误差。
示例图固定采用幅值 1.2 组的第一条轨迹，没有按预测效果挑选；约 20 时间后出现明显偏离。
这里只研究无噪声、摆角与角速度均已知、未来驱动已知的情况，不据此声称任意参数泛化或长期精确预测。

`model.py` 定义网络，`main.py` 完成模拟、训练与预测；研究参数集中在 `main.py` 顶部。
`results/` 包含权重、损失记录、分幅值指标、四张图以及 `predictions.npz`。
该数组文件包含 `time`、`truth`、`prediction`、`amplitude`、`phase0`；状态数组形状为 `(64, 801, 2)`，最后一维依次是展开摆角和角速度。
`rollout_error.png` 展示各预测时刻的跨轨迹 RMSE，统计方式不同于表中的整段 RMSE。

参考：[单摆方程与 RK4](https://www.myphysicslab.com/pendulum/chaotic-pendulum-en.html)；[PyTorch 权重保存与加载](https://docs.pytorch.org/tutorials/beginner/basics/saveloadrun_tutorial.html)。
